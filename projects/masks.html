PROJECT 03 / NARRATIVE LOGIC · DEDUCTION UI

《가면과 진실》

무대 뒤의 진실을 추적하는 미스터리 추리게임. 노아의 시간순 원인·결과 사고와 아드리안의 인물·시간·물증 교차 검증을 서로 다른 추리 UI로 구조화합니다. 이 페이지에는 사건의 정답이나 반전이 없습니다.

01 / MYSTERY DESIGN

추리를 게임이 대신하지 않도록

대화와 조사로 얻은 정보를 게임이 자동으로 정답에 연결해 버리면 플레이어는 추리를 관전하게 됩니다. 이 프로젝트는 관찰 → 가설 → 반증 → 재검토의 과정을 플레이어가 직접 완성할 수 있도록 정보를 구조화하는 데 집중합니다.

NOAH / 노아

작은 관찰에서 출발해 원인에서 결과까지 직선적으로 이어지는 시간순 사고. 빠르게 가설을 세우되 반증 앞에서는 수정합니다.

ADRIAN / 아드리안

증언·시간·인물·물증·다른 설명 가능성을 함께 놓고 교차 검증하는 다층 사고. 가능성을 제거하며 결론에 도달합니다.

02 / DUAL THINKING

두 사람의 사고를 UI로 표현하기

두 주인공의 성격 설명에 그치지 않고, 정보를 놓는 방식과 연결 방법 자체가 다르게 보이도록 추리 화면을 설계했습니다. 아래는 실제 사건과 무관한 익명 카드로 만든 스포일러 없는 UI 모형입니다.

노아: 관찰을 시간순으로 연결해 하나의 원인→결과 가설을 세웁니다.

설계 의도: 캐릭터가 답을 대신 말하지 않도록, 실제 단서와 반증 카드의 연결을 플레이어가 직접 완성하는 방식입니다.
03 / REASONING UI

노아와 아드리안, 같은 단서의 다른 구조

노아는 관찰을 순서대로 배치하고, 아드리안은 인물·시간·물증·반론을 교차하여 검토합니다. 실제 작업 화면으로 두 UI의 정보 구조를 비교할 수 있습니다.

스포일러 보호: 이 두 화면에는 1장의 실제 단서와 가설 문구가 일부 보입니다. 처음에는 단서 내용을 가린 상태로 표시하고, 클릭한 뒤 직접 공개할 수 있도록 했습니다.
04 / CORE LOOP

조사에서 최종 추리까지

대화→현장 조사→증거 획득→연결·추론→반론 검토
01

정보는 먼저 발견되어야 한다

정답을 아는 제작자의 시선과 초회 플레이어가 실제 접하는 정보를 구분합니다. 중요한 단서가 결론 이전에 제시되는지 검증합니다.

02

틀린 가설도 수정할 수 있어야 한다

새로운 증언이나 물증이 나오면 앞선 판단을 반증하고 다시 구조화할 수 있도록 설계합니다.

03

캐릭터 성격은 행동에서 드러나야 한다

인물 설정을 장황하게 설명하기보다 처음 만났을 때의 행동, 대화 반응, 표현의 차이가 성격을 보여주도록 합니다.

05 / GAMEPLAY UI

대화 → 조사 → 증거 → 연결

플레이어가 대화와 오브젝트 조사에서 단서를 얻고, 기록에서 다시 확인한 뒤 추론에 활용하는 흐름입니다. 기획에서 요구한 정보 탐색 단계를 실제 UI 화면으로 제시합니다.

위 화면은 사용자가 제공한 실제 프로젝트 캡처입니다. 각 화면의 기능별 최종 검증·저장 정상 작동 여부와 1장 완주는 별도 확인이 필요합니다.

06 / VISUAL SYSTEM

표정·연출·UI 디자인

버건디·금장·딥 네이비의 극장풍 UI와 인물의 표정 변화를 사용합니다. 모든 행동마다 새 일러스트를 만들기보다는 기본 스탠딩과 제한된 감정별 표정을 활용해 제작 비용과 일관성을 관리합니다.

VISUAL DIRECTION

  • 대화 화자 표시와 캐릭터별 이름표
  • 표정·크기·눈높이·투명 영역 통일
  • 단서 연결 UI는 인물별 사고 방식 차별화

07 / DESIGN CHANGES

기획 수정의 기준

A

노아를 단순한 실수 담당으로 만들지 않기

빠른 인과 추론을 노아의 실질적인 능력으로 정의했습니다. 단점을 드러내더라도 관찰력과 수정 능력이 먼저 보여야 합니다.

B

아드리안이 모든 답을 아는 인물로 보이지 않게

노아가 세운 선형 가설을 기반으로 인물·시간·물증·반론을 병렬로 확인하는 구조를 부여했습니다.

C

추리 공정성과 개발 가능성을 함께 검토

정답을 아는 제작자 시선과 최초 플레이 정보량을 분리하고, 대화·조사·저장 등 실제 기능을 유지하면서 UI와 스프라이트를 보정합니다.

SPOILER POLICY

공개 포트폴리오에는 범인, 범행 동기, 사건 트릭, 정답, 반전 및 제작자 전용 추론 자료를 포함하지 않습니다. 미스터리의 공정성 검증은 플레이 후 진행 예정인 항목으로 구분합니다.

08 / PRODUCTION STATUS

현재 제작 상태와 다음 증빙

CHAPTER 01 / UNITY WORK IN PROGRESS

1장 중심으로 Unity 대화·조사·추리·UI를 제작 및 수정하고 있습니다. 캐릭터별 표정 이미지와 장식 자산을 실제 게임에 적용하는 작업도 진행 중입니다. 이 페이지는 프로젝트의 시스템 의도와 디자인 과정을 소개하며, 1장 완주·실기 표정 전환·저장 테스트가 모두 완료됐다고 주장하지 않습니다.
